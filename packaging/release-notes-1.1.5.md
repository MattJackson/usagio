# usagio 1.1.5

- Clicking a reset spends that reset. If you have a session reset and a session + weekly reset, you can pick the session one and keep the full one banked; before, usagio always spent the first one the server listed.
- The reset section now says how many resets you have, what each clears, and to click one to use it. The confirmation says what stays banked afterwards.
- A reset that worked is reported as applied instead of "No reset applied: unknown".
